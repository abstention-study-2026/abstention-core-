# Working rules
1. Never push directly to main. Create a branch, push it, and open a pull request.
2. Another researcher reviews and merges every pull request.
3. Do not edit files owned by someone else without telling them.
4. Never change this repo from inside a model repo.
5. Every protocol decision goes in DECISIONS.md with the date.
6. Tags mark freeze points (core-pilot-v1, core-frozen, thresholds-locked). Only create a tag after all three agree.
